# Matix

یک پنل ساده‌ی VLESS-over-WebSocket با پشتیبانی ربات تلگرام — نوشته‌شده از صفر،
بدون هیچ وابستگی به پروژه‌های دیگه، برای اینکه راحت قابل فهم و توسعه باشه.

**این نسخه عمداً مینیمال نگه داشته شده.** فروشگاه، کیف پول، رفرال و هر منطق
تجاری دیگه‌ای نداره — فقط هسته‌ی کار:

- ساخت/مدیریت لینک‌های VLESS (حجم، مدت اعتبار، فعال/غیرفعال)
- تونل واقعی VLESS-over-WebSocket (بدون نیاز به Xray/V2Ray جدا)
- پنل وب ساده برای مدیریت
- ربات تلگرام ساده برای مدیریت از راه دور
- عضویت اجباری در چند کانال تلگرام (قابل افزودن/حذف نامحدود از خود ربات)

## ساختار پروژه

```
main.py           هسته‌ی FastAPI: API، auth، state، صفحات
vless_relay.py     پارس هدر VLESS + رله‌ی WebSocket<->TCP (کاملاً مستقل)
telegram_bot.py    ربات تلگرام (long-polling، بدون نیاز به webhook)
pages.py           HTML/CSS/JS پنل (بدون فریم‌ورک فرانت‌اند)
requirements.txt   وابستگی‌های پایتون
Procfile           دستور اجرا برای Railway/Heroku
.env.example       نمونه‌ی متغیرهای محیطی
```

## اجرای محلی

```bash
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # مقادیرش رو ویرایش کن
export $(cat .env | xargs)      # یا از python-dotenv استفاده کن
python3 main.py
```

بعد برو به `http://localhost:8000/dashboard` — رمز پیش‌فرض `admin123` هست
(از env عوضش کن).

## دیپلوی روی Railway

1. این ریپو رو به گیت‌هاب پوش کن (پایین توضیح داده شده)
2. توی Railway → New Project → Deploy from GitHub repo → همین ریپو رو انتخاب کن
3. یک Volume بساز و به مسیر `/data` وصلش کن (برای اینکه لینک‌ها با هر دیپلوی
   پاک نشن)
4. متغیرهای محیطی رو توی Railway → Variables ست کن:
   - `ADMIN_PASSWORD`
   - `TELEGRAM_BOT_TOKEN` (اختیاری)
   - `TELEGRAM_ADMIN_IDS` (اختیاری)
   - `DATA_DIR=/data`
5. Railway خودش `PORT` و `RAILWAY_PUBLIC_DOMAIN` رو تنظیم می‌کنه؛ نیازی به
   دست‌کاری نیست
6. بعد از دیپلوی، توی Settings → Networking یه دامنه‌ی عمومی فعال کن (اگه
   خودکار فعال نشده)

## عضویت اجباری در کانال

از منوی ربات (فقط برای ادمین‌ها): `⚙️ تنظیمات` → `📢 کانال‌های عضویت اجباری` →
`➕ افزودن کانال جدید`. می‌تونی هر تعداد کانال که بخوای اضافه کنی؛ کاربر عادی
تا وقتی توی همه‌شون عضو نشه، نمی‌تونه از ربات استفاده کنه.

⚠️ نکته‌ی مهم: **ربات باید توی هر کانالی که اضافه می‌کنی ادمین باشه**، وگرنه
تلگرام اجازه‌ی چک کردن عضویت رو بهش نمی‌ده و اون کانال به‌صورت خودکار از حالت
اجباری خارج می‌شه (برای اینکه یک کانال با تنظیمات اشتباه کل ربات رو قفل نکنه).

## چطور گسترشش بدی

این پروژه قصداً کوچیک نگه داشته شده تا معماریش شفاف باشه. چند نقطه‌ی
شروعِ خوب برای توسعه:

- **فروشگاه/پرداخت**: یه فایل `shop.py` بساز، endpoint سفارش اضافه کن، و از
  `main.make_link()` برای ساخت لینک بعد از تایید پرداخت استفاده کن
- **چند سرور/کلاستر**: چون هر لینک فقط یک UUID و متادیتاست، می‌تونی همین
  `state.json` رو بین چند نمونه از `main.py` (پشت یک لود بالانسر) به اشتراک
  بذاری، یا به Redis/Postgres مهاجرت کنی
- **QR کد**: می‌تونی از `https://api.qrserver.com/v1/create-qr-code/?data=...`
  به‌صورت `<img>` مستقیم توی `pages.py` استفاده کنی، بدون نیاز به کتابخونه‌ی
  سمت سرور
- **محدودیت سرعت/آی‌پی**: توی `vless_relay.run_tunnel` جای مناسبی برای اضافه
  کردن این منطق‌هاست، قبل از باز کردن اتصال TCP
- **چند کاربره کردن پنل**: الان فقط یک رمز عبور ادمین هست؛ برای چند ادمین،
  `AUTH` رو از یک دیکشنری تکی به لیستی از کاربرها تغییر بده

## نکات پروتکل

تونل روی مسیر `/ws/{uid}` کار می‌کنه. کلاینت (v2rayNG/NekoBox/Streisand و…)
باید با این تنظیمات وصل بشه:

- Protocol: VLESS
- Network: WebSocket (ws)
- Security: TLS
- Port: 443
- Path: `/ws/{uuid-همون-لینک}`
- Host/SNI: دامنه‌ی خودت

لینک `vless://...` که پنل/ربات می‌سازه همه‌ی این پارامترها رو خودش توش داره؛
کافیه کپی و توی کلاینت import کنی.
